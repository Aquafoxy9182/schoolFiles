== Inleiding

[.underline]#AsciiDoc# is een *eenvoudige* maar _krachtige_ markup-taal.
Je kunt lijsten maken:

* Item 1
* Item 2
* Item 3

Of tabellen:

|===
|Kolom 1 |Kolom 2
|Data 1 |Data 2
|Data 3 |Data 4
|===

== Conclusie

AsciiDoc is veelzijdig en geschikt voor technische documentatie!
